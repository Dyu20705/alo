# ALO First-Year Non-Goals

The following are excluded through v0.2 unless the product contract is deliberately revised.

## Platforms and deployment

- Kubernetes operator or admission controller.
- Multi-tenant SaaS or hosted control plane.
- Distributed graph database or mandatory PostgreSQL.
- High-availability daemon or multi-node replication.
- Web dashboard, graph visualization, or TUI.

## Runtime evidence

- eBPF process, file, network, DNS, or syscall sensor.
- OpenTelemetry collector or telemetry storage backend.
- Continuous runtime monitoring or alerting.
- Incident root-cause or causality claims.
- Runtime policy enforcement.

## Extension systems

- WASI/WASM plugin runtime.
- General plugin SDK before stable collector and evidence boundaries.
- Custom programming language or custom query language.

## Security and analysis products

- Vulnerability database or vulnerability scanner.
- SBOM viewer or license-compliance suite.
- SIEM, EDR, IDS, or security score.
- General policy engine or auto-remediation.
- AI analysis, AI agent, chatbot, or AI autofix.

## ML scope

- Model, dataset, training-run, evaluation, registry, or inference lineage implementation.
- AI BOM product features.

## Ecosystem replacement

- Replacement for GUAC, Sigstore, GitHub, registries, Docker, observability backends, or package databases.
- Full implementation of every SPDX, in-toto, SLSA, OCI, or GitHub Actions semantic.

## Deferred outputs

- SARIF.
- OpenTelemetry event export.
- HTML reports.
